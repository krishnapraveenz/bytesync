# Bytesync Technologies Website

![Bytesync Technologies](logo-light.png)

Official website for **Bytesync Technologies and Communications**, a leading IT solutions provider based in Palakkad, Kerala. This repository contains the source code for the company's responsive, SEO-optimized website.

🌐 **Live Site:** [https://bytesync.in](https://bytesync.in)

## 🚀 About The Project

Bytesync Technologies offers a wide range of digital services including:

- **Web Development**: Custom websites, E-commerce, and Web Applications.
- **Mobile App Development**: Android & iOS apps (Flutter/React Native).
- **Digital Marketing**: SEO, Social Media Marketing, and Branding.
- **Networking Solutions**: Cisco enterprise networking and infrastructure.
- **Cloud Services**: Cloud migration and hosting solutions.

This website serves as the digital storefront for these services, featuring a blog, portfolio showcase, and client testimonials.

## ✨ Key Features

- **Responsive Design**: Fully responsive layout that works perfectly on Desktop, Tablet, and Mobile.
- **Local SEO Optimized**: Targeted landing pages for local search terms in Palakkad and Kerala.
  - `/web-development-palakkad`
  - `/mobile-app-development-palakkad`
- **Schema Markup**: Extensive JSON-LD schema for LocalBusiness, Services, and SoftwareApps.
- **Dynamic Portfolio**: Filterable portfolio section showcasing recent projects.
- **Blog Section**: Technical blog with SEO-friendly articles.
- **Performance**: Optimized assets and fast loading times.
- **Dark/Light Mode**: User preference support.

## 🛠️ Technologies Used

- **HTML5 & CSS3**: Semantic HTML and modern CSS (Variables, Flexbox, Grid).
- **JavaScript (ES6+)**: Interactive elements, filtering, and animations.
- **Font Awesome**: Icons.
- **Google Fonts**: Typography (Inter, Space Grotesk).

## ⚙️ Getting Started

### Prerequisites

- Node.js installed on your machine.

### Installation

1.  **Clone the repository**

    ```bash
    git clone https://github.com/krishnapraveenz/bytesync.git
    cd bytesync
    ```

2.  **Install dependencies**

    ```bash
    npm install
    ```

3.  **Run Development Server**
    ```bash
    npm run dev
    ```
    This will start a local `live-server` at `http://localhost:3000`.
